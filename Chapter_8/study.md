### 8. 상속
##  8.1. 상속의 표현
#   8.1.1. 상속의 목적 및 장점
    - 간결한 클래스 작성
    - 클래스 간의 계층 분류 및 관리의 용이함
    - 클래스 재사용과 확장을 통한 소프트웨어 생산성 향상
#   8.1.2. 상속 관계로 클래스 간결화
    - 상위 클래스에 fuction을 작성했으면, 밑에꺼는 다 그 함수를 받을 수 있음.
#   외부에서 파생 클래스 객체에 대한 접근
    - public으로 정의된 기본 클래스의 함수에 접근해서 private 고칠 수 있음. -> 이것만 됨.
#   상속과 객체 포인터 - 업 캐스팅
    - 파생 클래스 포인터가 기본 클래스 포인터로 치환되는 것
    -> 상속 관계에서 강제 타입 변환 명시 생략가능
    - 기본 클래스 포인터는 기본 클래스의 public 멤버까지만 접근 가능
    -> 만약 파생 클래스 멤버에 접근하려고 하면 컴파일 오류
#   상속과 객체 포인터 - 다운 캐스팅
    - 기본 클래스의 포인터가 파생 클래스의 포인터에 치환되는 것
    -> 강제 타입 변환 명시 필요
    - Point* pBase, po;
    = Point* pBase; 
      Point po;
    -> 다운 캐스팅의 런타임 에러(실행 오류)
    pDer은 ColorPoint의 포인터 객체지만, 다운 캐스팅을 했으므로
    setColor멤버에서 컴파일 오류가 나지 않지만 런타임 에러가 발생함.

##  protected 접근 지정
    - 파생클래스에서만 접근 허용
    - 기본 클래스에서 접근 가능

##  상속 관계의 생성자와 소멸자 실행 순서
    - 1. 파생클래스의 생성자와 기본클래스의 생성자 둘 다 실행됨.
    - 2. 기본클래스 먼저 생성됨.
#   소멸될 때
    - 파생 클래스 소멸자 먼저 실행, 기본 클래스 소멸자 나중 실행
#   묵시적인 기본 클래스 생성자 선택
    - 선정 안해주면 디폴트 기본 생성자 들어감 (매개변수 없는거)
#   boolalpha
    - 불린 값을 true, false로 출력되게 하는 조작자(manipulator)

##  상속 지정
#   private, public, protected
    - 3개 다 지정가능
#   private
    - 기본 클래스의 protected, public 멤버를 private로 계승
#   public
    - 기본 클래스의 모든 멤버 속성을 그대로 계승
#   protected
    - 기본 클래스의 protected, public 멤버를 protected로 계승
