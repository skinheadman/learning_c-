### 11. C++ 입출력 시스템
##  11.1. C++ 입출력 기초
#   11.1.1. 스트림 개념
    - 스트림 : 흐르는 시냇물, 연속적인 데이터의 흐름 혹은 데이터를 전송하는 소프트웨어 모듈
    - 바이트 단위로 입출력함.
    - 입력스트림 : 키보드, 네트워크, 파일 등 입력 장치로부터 입력된 데이터를 순서대로 프로그램에 전달하는 객체
    - 출력 스트림 : 프로그램에서 출력한 데이터를 프린터나 하드 디스크, 스크린, 네트워크, 파일 등과 같은 목적 장치로 순서대로 내보내는 객체
    - C++ 응용프로그램은 출력 스트림에 출력, 입력 스트림에 입력
    - cin : C++ 표준 입력 스트림 객체 / cout : 표준 출력 스트림 객체
#   11.1.2. C++ 입출력 스트림 버퍼
    - 입력 스트림 버퍼 : 입력된 데이터를 프로그램에 전달하기 전에 일시 저장하는 공간
        - 키 입력 스트림 버퍼 : cin 입력 스트림 -> 'Hello' -> 'o','l','l','e','H' 들어온 순서대로 오른쪽에 저장 -> 가장 최근에 입력된 문자가 왼쪽 
        - Backspace : 버퍼를 제어하는 제어키
        - <Enter> 키 : 입력 제어키
    - 출력 스트림 버퍼 : 출력 장치로 보내기 전에 데이터를 일시 저장하는 공간
        - 1차적 출력 스트림 버퍼에 저장 
        - '\n'이 도착하거나 버퍼가 가득 차면 스크린에 출력
        - cout.flush() -> 버퍼에 있는 내용 모두 장치에 출력
    - 버퍼의 필요성
        1. 운영체제 API를 호출하여 입출력 장치와 프로그램 사이에서 데이터 전송
        2. 파일 출력 스트림의 경우 -> 버퍼 없으면 바이트 단위로 파일 쓰기 실행시 운체API 호출, 운체API는 하드 디스크에 명령-> 파일 기록 
            -> 하드 디스크와 네트워크 장치의 많은 작동 -> 시스템 효율 저하
        3. 버퍼가 있으면, 쓰기가 이루어진 데이터 스트림 버퍼에 저장, 한번에 운체 API 호출을 통해 시스템 효율 증가
        4. 키 입력 스트림의 경우, 사용자가 입력한 키를 일단 버퍼에 저장, 프로그램에 전달하기 전에 <Backspace>키를 통해 입력된 키 수정
#   11.1.3. C++ 표준은 스트림 입출력만 지원
    - 저수준 입출력 방식(row level console I/O)
        - 버퍼 없음.
    -  표준 C++ 에서는 스트림 입출력만 다룸.
    - 저수준 입출력 방식은 특정 컴파일러에 종속되어 다른 컴파일러에서 컴파일 되지 않음.
    - 스트림 입출력은 모든 컴파일러에서 호환
#   11.1.4. C++ 입출력 라이브러리
    - ANSI/ISO C++ -> 2003 C++ 입출력 표준 대폭 수정
    - 템플릿을 이용하여 재작성
    - 과거에는 한바이트만 저장
        -> ios, istream, ostream, iostream, ifstream, ofstream, fstream 문자를 한 바이트로 다루는 클래스
    - 현 표준 C++ 입출력 라이브러리
        -> template 사용
        -> basic_ios, basic_istream, basic_ostream, basic_ifstream, basic_ofstream, basic_fstream
#   11.1.5. C++ 표준 입출력 스트림 객체
    - cin : 키보드 장치와 연결된 istream 타입의 표준 입력 스트림 객체
    - cout : 스크린 장치와 연결된 ostream 타입의 표준 출력 스트림 객체
    - cerr과 clog : 표준 오류 출력 스트림 객체, clog는 버퍼를 거치지만, cerr는 버퍼를 거치지 않고 스크린에 오류 메시지 출력력

##  11.2. ostream의 멤버 함수를 이용한 문자 출력

    - 출력 버퍼에 있는 문자들을 모두 강제로 출력
        -> flush()가 필요없는 경우 : 컴파일러에 따라 다름(put(),write() 함수가 문자를 버퍼에 기록한 후 바로 버퍼를 출력하는 경우도 있음.)

##  11.3. istream의 멤버 함수를 이용한 문자 입력
#   11.3.1. 문자 입력
    - int get() / istream& get(char& ch)
        -> int get() : 입력 스트림에서 문자를 읽어 리턴, 오류나 EOF를 만나면 -1(EOF) 리턴
            -> 입력 스트림에서 한 개의 문자를 읽어 리턴
            -> <Enter> 키 등의 공백 문자도 읽어 리턴
            -> 사용자가 <Enter> 키 입력시 읽기 시작
            -> get() 은 문자를 리턴하지만, 입력 스트림의 끝을 만나면 EOF 리턴
            -> EOF가 int 타입으로 선언되어 있기 때문에 get()의 리턴 타입은 int다.
        -> istream& get(char& ch) : 입력 스트림에서 문자를 읽어 ch에 저장. 현재 입력 스트림 객체(*this)의 참조 리턴, 오류나 EOF를 만나면, 스트림 내부의 오류 플래그(fallbit) 세팅
            -> 공백 문자를 읽어 리턴 가능
    - 문자열 입력
        -> istream& get(char* s, int n); // 입력 스트림으로부터 n-1개의 문자를 읽어 배열 s에 저장하고 마지막에 '\0' 문자 삽입. 입력 도중 '\n'을 만나면 '\0'을 삽입하고 리턴
        - 입력 도중 '\n'을 만날 때
            -> 입력 스트림에서 '\n' 문자를 만나면 읽기를 중단하고 리턴하여, '\n'이 입력 스트림 버퍼에 남아있음.
            -> 만일 이 상태에서 다시 읽기를 하게 되면 입력 스트림에 남아있는 '\n'부터 읽기 시작해 아무것도 읽지 않고 바로 리턴함.
            -> 무한루프에 빠질 수도 있음. -> cin.get() or cin.ignore(1)로 '\n'문자 제거
        - 입력 도중 EOF나 오류가 발생할 때
            -> get()은 읽기 도중 EOF(ctrl-z)를 만나거나 오류가 발생하면 읽기 중단, '\0'를 배열에 삽입하고 리턴함.
    - 한 줄 읽기
        -> istream& get(char* s, int n, char delim='\n) : 입력 스트림으로부터 최대 n-1개의 문자를 읽어 배열 s에 저장하고 마지막에 '\0' 문자 삽입. 입력 도중 delim에 지정된 구분 문자를 만나면 지금까지 읽은 문자를 배열 s에 저장하고 리턴
        -> istream& getline(char* s, int n, char delim='\n') : get과 동일, 하지만 delim에 지정된 구분 문자를 스트림에서 제거
    - 입력 스트림의 문자 건너 띄기
        -> istream& ignore(int n=1, int delim=EOF) : 입력 스트림에서 n개 문자 제거. 도중에 delim 문자를 만나면 delim 문자를 제거하고 리턴
    - 읽은 문자 개수 알아내기
        -> int gcount() : 최근에 입력 스트림에서 읽은 바이트 수(문자의 개수) 리턴. <Enter> 키도 개수에 포함.

##  11.4. 포맷 입출력
#   11.4.1. 포맷 플래그
    - 데이터의 출력을 원하는 대로 조작하기 위해 사용하는 옵션
    - C++ 입출력 스트림은 32개의 포맷 플래그를 저장하는 멤버 변수를 두고, 이를 참조함.
    - 모든 입출력 스트림에서 공통으로 사용되므로 ios 클래스에 정수형 상수로 정의되어 있다.
    - 하나의 플래그는 한 비트로 표현, 한 가지 포맷 정보를 표현한다.
    - cin, cout은 입출력 시 이 포맷 변수에 세팅된 플래그 값을 반영하여 포맷 입출력을 수행함.
    - 포맷 변수를 적절히 설정하면 입출력 포맷 제어 가능
    - 포맷을 지정하는 함수 / 지정된 플래그를 해제하는 함수
        -> Long setf(Long flags) : flags를 스트림의 포맷 플래그로 설정하고 이전 플래그 리턴
        -> Long unsetf(Long flags) : flags에 설정된 비트 값에 따라 스트림의 포맷 플래그를 해제하고 이전 플래그를 리턴
    - 비트-OR(|) 연산
        -> 여러 플래그들을 비트-OR(|)연산으로 합치면 여러 포맷을 동시에 지정 가능
        -> cout.setf(ios::dec | ios::showpoint) : 10진수 표현과 동시에 실수의 경우 소숫점 이하 나머지 빈 칸은 0으로 출력
    - 포맷 플래그는 한번 설정하면 해제할 때까지 유지됨.
#   11.4.2. 포맷 함수 활용 - 너비 설정, 빈칸 채우기, 유효 숫자 자리수 지정
    - ostream 클래스의 멤버 함수 width(), fill(), precision() 은 각각 출력되는 필드의 너비, 유효 숫자 개수, 빈칸을 채우는 문자 등을 지정하는데 사용됨.
    - << 연산자를 이용하여 출력될 때만 사용
    - 필드의 최소 너비 지정, width()
        -> 하나의 필드가 차지하는 화면의 최소 너비를 지정함.
        -> int width(int minWidth) : 출력되는 필드의 최소 너비를 minWidth로 설정하고 이전에 설정된 너비 값 리턴
        -> 호출 직 후 하나의 필드에만 적용되므로 주의 필요
        ex. cout.width(10);
            cout << "Korea/" << "Seoul/" << "City";
        => 출력 :          Korea/Seoul/City
    - 필드의 빈 공간 채우기, fill()
        -> 필드의 실제 크기가 width()에 의해 정의된 너비보다 작을 때, 남은 칸은 빈칸으로 채워짐. 빈칸을 채울 문자 지정
        -> 한번 실행되면 계속 들어가는 함수
        -> char fill(char cFill)
    - 유효 숫자 자리수 지정, precision()
        -> 출력 스트림은 숫자를 출력할 때 유효 숫자 자리수를 디폴트 6으로 지정
        -> 유효숫자의 자리수를 바꿔주는 함수
        -> 즉, 소수점 뒷자리를 지정
#   11.4.3. 조작자
    - 스트림 조작자  함수 
    - ANSI/ISO 표준 C++ 헤더파일에 정의된 특별한 원형을 가진 함수
    - 매개 변수 1개, 매개 변수 없는 조작자로 나뉨
    - 항상 <<, >> 연산자와 함께 사용됨.
    - 종류(매개 변수 x)
        - hex : 16진수 형식으로 포맷
        - showbase : 숫자의 진수를 표기
        - endl : 버퍼에 있는 데이터를 모두 출력하고 한 줄 띄도록 포맷
        - dec : 10진수 형식으로 포맷
        - showpos : + 부호 붙이기기
    - 매개 변수를 가지는 조작자
        - <iomanip> 헤더 파일에 정의됨.
    - 종류(매개 변수 1)
        - resetioflags(long flags) : flags에 지정된 플래그들 해제
        - setbase(int base) : 베이스를 출력할 수의 진수 지정
        - setfill(char cFill) : 필드를 출력하고 남은 공간에 cFill 문자로 채움
        - setioflags(long flags) : flags를 스트림 입출력 플래그로 설정
        - setprecision(int np) : 출력되는 수의 유효 숫자 자리수를 np개로 설정, 소수점은 별도로 카운트
        - setw(int minWidth) : 필드의 최소 너비를 minWidth로 지정
    - 조작자 특징
        - 사용하기 쉽고 출력 코드를 간결하게 제작
        - 조작자로 설정한 포맷은 한 번의 입출력에만 적용, 입출력마다 포맷지정 필요
        - 대부분의 조작자는 내부에서 setf() 함수 호출

##  11.5. 삽입 연산자(<<) 와 추출 연산자(>>)
#   11.5.1. 삽입 연산자의 중복
    - << 연산자 : 삽입 연산자, 삽입자
    - 정수를 비트 단위로 시프트하는 C++ 기본 연산자
    - 다양한 값을 출력할 수 있도록 ostream 클래스에 중복 작성
#   11.5.2. 삽입 연산자의 실행 과정
    - 리턴 타입이 의미하는 것
        - ostream& operator << (char c)
        - 출력스트림에 데이터를 삽입한 후, 출력 스트림(*this)를 리턴
        - 스트림의 참조가 리턴됨
        - 만약 리턴 타입이 ostream일 경우
            - 스트림의 복사본이 리턴됨.
            - 그 다음에 실행되는 << 연산은 복사된 스트림에 출력
            - 연속되는 두 << 연산이 서로 다른 출력 스트림에 출력하게 됨.
    - 구체적인 실행 과정
        ex. cout << 'a' << 123;
        1. << 연산자 함수 호출
        2. cout의 연산자 함수 ostream& operator << (char c) 실행
            - 문자 'a'를 현재 스트림(cout)의 버퍼에 저장
            - 버퍼가 꽉차면 화면에 출력
            - 현재 스트림에 대한 참조 리턴
        3. << 123 실행
            - 'a'가 들어있는 cout의 버퍼에 123출력
            - char 형과 동일
#   11.5.3. 사용자 삽입 연산자(<<) 만들기
    1. Point 클래스 제작
    2. 외부함수로 << 연산자 함수 작성
    3. friend 등록
    - 사용자 정의 삽입 연산자 함수의 원형
        - ostream& operator << (ostream& outs, UserClass obj);
        - ostream& operator << (ostream& outs, UserClass& obj);
        -> 둘다 가능
        - 외부 함수로만 작성되어야 함.
        - UserClass의 private 멤버에 접근하는 경우, UserClass에 프렌드 선언 필요
#   11.5.4. 추출 연산자의 중복
    - >> 연산자 : 추출 연산자
    - cin으로부터 키를 입력받기도 하지만, 파일에서 읽을 때도 사용됨.
    - 다양한 >> 연산자를 istream 클래스에 중복 작성
#   11.5.5. 사용자 추출 연산자(>>) 만들기
    - 실행 과정은 삽입 연산자의 실행 과정과 흡사
    1. Point 클래스 제작
    2. 외부 함수로 >> 연산자 함수 작성
    3. 모든 매개 변수를 참조 타입으로 선언 -> 원본 객체에 값을 쓰기 위해서
    4. friend 등록
    - 사용자 정의 추출 연산자 함수의 원형
        - istream& operator >> (istream& ins, UserClass& obj)
