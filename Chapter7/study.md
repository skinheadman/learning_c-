###  7.프렌드와 연산자 중복
##  7.1. C++ 프렌드 개념
#   7.1.1. 친구와 C++ 프렌드
    - 클래스 외부에 작성된 함수를 클래스 내에 friend 키워드로 선언하여, 클래스의 멤버 함수와 동일한 접근 자격 부여 가능
    - 상속되지는 않는다.
    - friend 키워드로 선언된 외부 함수 = 프렌드 함수
    - 클래스의 모든 변수나 함수에 접근 가능
    - 오직 함수만 선언가능
    - 필요성
        - 클래스 멤버 함수로 적합하지는 않지만, private, protected 멤버를 접근해야하는 경우
    - 연산자 함수 : 프렌드 함수의 가장 대표적인 예시
    - 선언할 수 있는 경우
        - 클래스 외부에 작성된 함수를 프렌드로 선언
        - 다른 클래스의 멤버 함수를 프렌드로 선언
        - 다른 클래스의 모든 멤버 함수를 프렌드로 선언
#   7.1.2. 프렌드 함수 선언
    - 클래스 외부에 구현된 함수를 friend 키워드를 사용하여 클래스 내의 아무 곳에나 선언
    - 전방 참조(forward reference) 문제 해결을 위한 전방 선언(forward declaration)
        - backward reference : C++에서는 변수나 함수, 클래스의 이름을 먼저 선언한 후 그 이름(identfier)을 참조하는 backward reference가 원칙
        - forward reference : 대부분 컴파일 오류
            - 해결 방법 : 전역 함수로 설정한 함수 앞에 클래스, 변수, 함수 등의 이름을 먼저 선언하여 문제 해결 (=forward reference)
#   7.1.3.  프렌드 멤버 선언
    - 다른 클래스의 멤버 함수를 클래스의 프렌드 함수로 선언
        - friend 자료형 클래스명 :: (범위 지정 연산자) 함수명(매개변수,...);
#   7.1.4.  프렌드 클래스 선언
    - 다른 클래스의 모든 멤버 함수를 클래스의 프렌드 함수로 선언
        - friend 클래스명;
#   tip
    - friend를 선언하는 위치
        : 프렌드 선언은 클래스 내에 private, public 영역 등 아무 위치에나 가능함.
    
##  7.2. 연산자 중복
#   7.2.1. 연산자 중복의 개념
    - 다형성 : 동일한 연산 혹은 기호를 대상(피연산자)에 따라 서로 다른 의미로 해석하는 일종의 다혛성
    - 함수 중복 : 같은 이름의 함수를 여러 개 만들 수 있음.
    - 연산자 중복 : 피연산자에 따라 서로 다른 연산을 하도록 동일한 연산자를 중복해서 작성하는 것
    - 피연산자 : 피연산자에 적합한 연산자를 새로 작성하면 프로그램이 보다 쉽게 표현
#   7.2.2. 연산자 중복의 특징
    - 본래 있는 연산자만 중복 가능하다. : ##, %% 막 이런거 안됨
    - 피연산자의 타입이 다른 연산을 새로 정의하는 것 : 객체+수, 수+객체, 객체+객체 이렇게 되어야 함.
    - 함수를 통해 이루어진다. : 새로운 연산 처리를 수행하는 함수를 구현하는 것 - 연산자 함수
    - 연산자 중복은 반드시 클래스와 관계를 가진다. : 무조건 피연산자에 객체를 동반, 그래서 전역함수 설정 후 프렌드 함수로 가거나, 클래스의 멤버 함수로 구현
    - 연산자 중복으로 피연산자의 개수를 바꿀 수 없다. : 피연산자가 1개 혹은 3개인 연산자로 중복할 수 없다.
    - 연산의 우선순위를 바꿀 수 없다.
    - 모든 연산자가 중복 가능한 것은 아니다.
#   7.2.3. 연산자 함수 선언과 연산자 함수 개요
    - 작성 방법
        - 클래스의 멤버함수로 구현
        - 외부함수로 구현하고 클래스의 프렌드 함수로 선언
        - 리턴타입(=자료형) operator 연산자(매개변수리스트);
    - 외부 함수로 구현하고 클래스에 프렌드 함수로 선언하는 경우
        : class(or 자료형) operator 연산자(매개변수2개);
        - 클래스 안에서 friend 선언해줘야함.
    - 클래스의 멤버 함수로 선언되는 경우
        - 오른쪽 피연산자만 매개변수 op2에 설정되고, 왼쪽 피연산자는 객체 자신
    - operator+() 나 operator + () 나 상관없음

##  7.3. 이항 연산자 중복
    - 이항 연산자 : 피연산자가 2개인 연산자
    - + 연산자 중복
        - 연산자 착안 : +의 의미 결정
        -> 연산자 함수 선언 : 컴파일러가 판단, c = a + b 가 c = a. + (b) 형식으로 변환됨. - 컴파일러에 의해
        -> 연산자 함수 구현 : 의미에 맞게 적당히 구현, 리턴타입에 맞는 객체(변수) 리턴
        ex. power 함수
            Power Power::operator + (Power op2) {
                Power tmp;
                tmp.kick = this->kick + op2.kick;
                tmp.punch = this->punch + op2.punch;
                return tmp;
            }
            -> 참조 매개 변수 사용 가능
    - 연산자 함수의 참조 매개 변수와 리턴 타입
        : 참조 매개 변수를 사용해도 무관, 사용하면 값이 바뀔 수도 있기 때문에 조심해야 함.

    - == 연산자 중복
        - 연산자 착안 : 대부분 bool형
        -> 연산자 함수 선언 : 컴파일러가 판단, a==b 가 a. == (b) 형식으로 변환됨. - 컴파일러에 의해
        -> 연산자 함수 구현 : 
            bool Power::operator == (Power op2) {
                Power tmp;
                if(kick==op2.kick && punch == op2.punch) return true;
                else return false;
            }
    - += 연산자 중복
        - 연산자 착안 : a와 b를 합쳐 a를 새로운 파워로 갱신
        -> 연산자 함수 선언 : (a+=b)이면 +=b 연산은 원본 객체 a가 아닌 복사본에 b를 더하는 것이므로 연산자 Power의 리턴타입을 Power& 으로 해야함.
            -> a+=b == a. += (b)
        -> 연산자 함수 구현 : 
            Power& Power::operator+=(Power op2) {
                kick = kick+op2.kick;
                punch = punch+op2.punch;
                return *this; // 리턴타입이 Power& 이므로 객체 자신이 참조 리턴 되어야 함.
            }
    - + 연산자 작성 실습 : b = a + 2;
        - 연산자 착안 : a의 kick과 punch 값에 각각 2를 더한 결과를 리턴하는 것으로 정의
        - 연산자 함수 선언 : b = a + 2 => a. + (2) => Power Power::operator + (int op2);
        - 연산자 함수 구현 : 
            Power Power::operator+(int op2) {
                Power tmp;
                tmp.kick = kick + op2;
                tmp.punch = punch + op2;
                return tmp;
            }

##  7.4. 단항 연산자 중복
    - 단항 연산자 : 피연산자가 하나인 연산자 함수
    - 단항 연산자의 종류 : 전위 연산자, 후위 연산자
        - 전위 연산자 : 연산자가 피연산자 앞에 오는 경우 ex. !op, ~op, ++op, --op
        - 후위 연산자 : 연산자가 피연산자 뒤에 오는 경우 ex. op++, op--
### 7.4.1. 전위 ++ 연산자 중복
    - 연산자 착안
        -> ++a는 객체 a의 모든 멤버들의 값을 1씩 증가시킨 후, 변경된 객체 a의 참조를 리턴하는 것을 호출
    - 연산자 함수 선언
        -> operator++() 연산자 함수 호출
        -> a . ++ ();
        -> return type : Power& -> 참조 리턴
    - 참조를 리턴하는 연산자 함수 구현
        -> operator++() 연산자 함수의 내용
            Power& Power::operator++() {
                kick++;
                punch++;
                return *this; // 변경된 객체 자신(객체a)의 참조 리턴
            }
### 7.4.2. 후위 ++ 연산자 중복
    - 연산자 착안
        -> a++는 객체 a의 모든 멤버를 1씩 증가시키지만, 증가 이전의 객체 a를 리턴하는 것으로 정의한다.
        -> a++는 I-value가 될 수 없으므로 ++는 참조를 리턴하면 안된다.
    - 연산자 함수 선언
        -> operator++(int) 연산자 함수 호출
        -> a .++(int);
        -> return type : Power -> 참조 리턴 x
    - 연산자 함수 구현
        -> operator++(int) 연산자 함수의 내용
            Power Power::operator++(int x) {
                Power tmp = *this;
                kick++;
                punch++;
                return tmp; // 증가 이전의 객체 리턴
            }
##  7.5 프렌드를 이용한 연산자 중복
    - 연산자 함수는 클래스 바깥의 외부 전역 함수로도 작성 가능
### 7.5.1. 2+a를 위한 +연산자 함수 작성
    - + 연산자 외부 함수로 작성
        -> 2.+(a)가 아님, 2는 객체가 아닌 상수이기 때문 -> +(2,a) 형태가 되어야 함.
    - 연산자 함수 구현
        -> Power operator + (int , Power) 연산자 함수의 내용
            Power operator+ (int op1, Power op2) {
                Power tmp;
                tmp.kick = op1 + op2.kick;
                tmp.punch = op1 + op2.kick;
                return tmp;
            }
    - 외부 연산자 함수의 프렌드 선언
        -> Power class 내의 operator+(int, Power) 함수의 friend 선언을 통해 private 멤버에 접근할 수 있다.
### 7.5.2. + 연산자를 외부 프렌드 함수로 작성
    - 연산자 함수 작성
        Power operator + (Power op1, Power op2) {
            Power tmp;
            tmp.kick = op1.kick + op2.kick;
            tmp.punch = op1.punch + op2.punch;
            return tmp;
        }
    - 컴파일러에 의한 변환 : c = a + b => c = +(a, b);
    - friend 선언
### 참고
    - 동일한 연산자 함수를 멤버 함수와 프렌드 함수로 동시 구현할 수 없다.
### 7.5.3. 단항 연산자 ++를 프렌드로 작성하기
    - 연산자 함수 구분 : 전위 ++ 연산, 후위 ++ 연산
    - 연산자 함수 작성
        1. 전위 연산자
            - 컴파일러에 의한 변환 : ++a => ++ (a);
            - Power& operator ++ (Power& op) {
                op.kick++;
                op.punch++;
                return op;
            }
        2. 후위 연산자
            - 컴파일러에 의한 변환 : a++ => ++(a, 0);
            - Power operaotr ++ (Power& op, int x) {
                Power tmp = op;
                op.kick++;
                op.punch++;
                return tmp;
            }
    - 참조 매개 변수와 참조 리턴 사용
        - 두 연산자 함수는 모두 참조 매개 변수 Power& op를 사용하며, 전위 연산자의 경우 참조를 리턴함.
        - 참조 매개 변수 사용 x 시 : 매개 변수 op에 a의 복사본이 전달되므로, op 객체의 kick과 punch 값을 증가시켜도 객체 a는 변하지 않음. => 값에 의한 호출로 인한 얕은 복사
        - 참조 매개 변수 사용을 통해 op는 객체 a를 참조하여 op 변경 시, 객체 a 변경
#   참고
    - 연산자 함수는 멤버 함수가 바람직함.
        - 새로운 연산자는 클래스와 연계하여 작동하기 때문
        - 멤버로 선언하면 friend를 취할 필요 없고, 가독성 높아짐.
        - 하지만, 2 + a 처럼 + 연산자를 외부 함수로 밖에 만들 수 없는 경우 friend를 취해 주어야 함.
    - 연산자 함수는 디폴트 매개 변수를 가질 수 없음.
##  7.6 참조를 리턴하는 << 연산자 작성
### 7.6.1. 연산자 착안
    - <<를 통해 더하기 연산 구현
### 7.6.2. 연산자 함수 구현
    - a<<3의 실행 후 다음 '<<5' 연산이 객체 a에 대해 진행되려면, 'a<<3' 에서 연산자가 <<연산 이후 객체 a를 참조 리턴 해야함.
    - 컴파일러의 변형 : a<<3 => a .<<(3);
    - 연산자 함수 구현
        class Power {
            ...
            Power& operator << (int x);
        };

        Power& Power::operator << (int x) {
            kick += x;
            punch += x;
            return *this; // 이 객체의 참조 리턴
        }
