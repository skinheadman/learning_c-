### 객체 포인터와 객체 배열, 객체의 동적 생성
##  4.1 객체 포인터
    4.1.1. 객체에 대한 포인터 선언 : 클래스명 *<포인터 변수명>
    4.1.2. 포인터 변수에 객체 주소 지정 : <포인터 변수명> = &<객체의 이름> -> 객체의 주소를 &연산자를 통해 포인터 변수에 저장
        - 포인터 변수 선언시, 객체의 주소로 초기화 가능
    4.1.3. 포인터를 이용한 객체 멤버 접근
        - 기존 객체이름으로 멤버에 접근할 때 : "." 사용
        - 객체 포인터로 멤버에 접근할 때 : "->" 사용 (포인터 변수가 가리키는 객체의 함수 멤버에 접근) / "(*<포인터 객체명>).멤버함수" 로 접근할 수도 있다.
        - 초기화하지 않은 객체 포인터를 이용하면 오류가 발생한다.
##  4.2. 객체 배열
    4.2.1. 객체 배열 선언 및 활용
        - 객체 배열 : 원소가 객체라는 점을 제외하고 int, char 등 기본 타입의 배열을 선언하고 활용하는 방법과 동일
        - 객체 배열 선언
            - <클래스 명> <객체 배열> [배열의 크기(int 형)]
            - 객체 배열 선언문은 기본 생성자를 호출함 (배열의 크기에 비례하여 기본 생성자를 호출한다. 3개면 기본 생성자 3개 호출)
                -> 매개 변수를 포함한 생성자가 있을 경우 기본 생성자를 컴파일러가 자동생성하지 않으므로 배열을 선언하면 컴파일 오류가 발생한다.
            - 객체 배열 사용 : 객체 배열의 각 원소는 [] 연산자로 구분/ 이때, . 연산자를 사용한다.
                -> "->"를 사용하려면 배열 명을 포인터 변수에 참조하면 됨. 이때, 배열의 다음 객체로 넘기기 위해서는 <포인터 변수> ++ 를 해주면 된다.
            - 배열 소멸과 소멸자 : 함수가 소멸할 때, 배열 소멸, 높은 인덱스에서부터 원소 객체가 소멸, 각 객체마다 소멸자 실행
    4.2.2. 다차원 객체 배열
        - 그냥 다차원 배열 선언하듯이 선언하면 됨. ex. Circle circles[2][3] : 2행 3열의 다차원 배열 선언
        - { } 안에 생성자를 지정하여 배열 초기화 가능
        - 원하는 배열에 .을 지정하고 이에 초기화하는 함수를 붙여 배열 초기화 가능
##  4.3. 동적 메모리 할당
    4.3.1. 동적 메모리 할당
        - new 연산자와 delete 연산자
            - new 연산자 : heap이라는 공간에서 메모리 할당
            - delete 연산자 : 할당받은 메모리를 heap에 반환
        - new 와 delete의 활용
            - <데이터 타입> *<포인터 변수> = new <데이터 타입> : 메모리 동적할당
            - delete <포인터 변수> : 할당된 메모리 반환
            - 힙 메모리가 부족하면 new는 NULL을 리턴
        - 동적할당 메모리 초기화
            - <데이터 타입> *<포인터 변수> = new <데이터 타입> (초깃값) : 초깃값으로 초기화 가능
        - delete 사용시 주의점
            - 동일한 메모리를 두 번 반환하거나 동적으로 할당받지 않은 메모리를 반환하면 실행오류가 생김.
    4.3.2. 배열의 동적 할당 및 변환
        - <데이터 타입> *<포인터 변수> = new <데이터 타입> [배열의 크기] // 배열의 동적 할당
        - delete [] <포인터 변수> // 배열 메모리 반환
        - 배열 초기화 시 주의사항 : 생성자를 통해 직접 '초깃값'을 지정할 수 없음.
            -> 배열 초기화 방법 : <데이터 타입> *<포인터 변수> = new <데이터 타입> [] { 배열의 원소값 }
        - 배열 delete 시 주의사항 : 배열이면 중간에 [] 를 붙여줘야 함. 배열이 아니면 [] 붙이면 안됨. -> 잘못된 메모리 반환이라는 문제 발생생
        - malloc 과 free : 선언하려면 <cstdlib>를 include 해줘야 함.
##  4.4. 객체와 객체 배열의 동적 생성 및 반환
    4.4.1. 객체의 동적 생성 및 반환
        - new를 이용한 객체의 동적 생성과 생성자
            - <클래스 이름> *<포인터 변수> = new <클래스 이름> // 기본 생성자 호출
            - <클래스 이름> *<포인터 변수> = new <클래스 이름>(생성자 매개 변수 리스트) // 매개 변수 있는 생성자 호출
        - delete를 이용한 객체 반환과 소멸자
            - delete <포인터 변수>
            - delete는 new로 동적할당 받은 것만 가능
    4.4.2. 객체 배열의 동적 생성 및 반환
            - <클래스 이름> *<포인터 변수> = new <클래스 이름> [배열 크기] // 배열 크기만큼의 객체 배열 생성
            - 초기화는 위의 배열과 동일
        - 객체 배열의 사용
            - 보통 객체 배열처럼 사용, 함수 참조시 . 붙이기
            - (객체 배열명 + 수)->함수명 으로 사용할 수도 있음. 숫자번째 배열로 이동
        - 배열의 반환과 소멸자
            - 위와 동일
            - 생성의 반대순으로 소멸(위와 동일)
        - 동적으로 할당받은 메모리의 반환 : 프로그램마다 힙이 따로 주어지기 때문에 다른 프로그램에 영향을 주지는 않으나, 메모리 누수가 생길 시 할당받지 못할 수도 있음.
          프로그램 종료시, 힙 전체가 운영체제에 의해 반환됨.  
##  4.5. this 포인터
    4.5.1. this의 기본 개념
        - this는 포인터
        - 객체의 멤버 함수가 호출될 때, 컴파일러에 의해 보이지 않게 전달되는 객체(private 선언된 객체)에 대한 주소
    4.5.2. this와 객체
        - this는 객체 자신에 대한 포인터
        - this는 컴파일러에 의해 탄생하는 변수
        - this는 어떤 헤더파일도 include 하고 있지 않음.
        - this의 선언 구조
            - this는 컴파일러에 의해 묵시적으로 삽입된 매개 변수이다.
            - 컴파일러는 모든 멤버 함수에 매개 변수 "<class> *this" 삽입
            - 멤버 함수를 호출하는 경우, 컴파일러는 묵시적으로 객체의 멤버 함수를 호출하는 문장을 변환하여, 해당 객체의 주소가 매개 변수로 전달되도록 만듦.
                -> 즉, 자동으로 함수를 주소에 넣어준다. &연산자를 이용하여
        - this가 필요한 경우
            - 멤버 변수의 이름과 동일한 이름으로 매개 변수 이름을 짓는 경우
            - 객체의 멤버 함수에서 객체 자신의 주소를 리턴할 때(연산자 중복을 구현할 때)
        - this의 제약 조건
            - 클래스의 멤버함수에게만 사용 가능
            - 정적 멤버 함수는 사용할 수 없음
##  4.6. string 클래스를 이용한 문자열 사용
    4.6.1. string 클래스 개요
        - C-스트링 : C언어에서 사용, '\0'으로 끝나는 문자 배열
        - string 클래스 : C++ 표준 라이브러리에서 제공하는 클래스 / 사용하려면 string헤더 파일을 include 해줘야함.
            - 문자열에 맞추어 메모리 자동 조절
    4.6.2. string 객체 및 출력
        - string 객체 생성 : 생성자를 이용하여 다양하게 문자열 생성
            {
                "생성자" : "설명"
                string() : 빈 문자열을 가진 스트링 객체 생성
                string(const string& str) : str을 복사한 새로운 스트링 객체 생성
                string(const char* s) : C-스트링 s의 문자열을 복사하여 스트링 객체 생성
                string(const char* s, int n) : 문자 배열 s에서 n개의 문자를 복사하여 스트링 객체 생성
            }
        - string 객체가 가진 문자열 출력 : 그냥 string 객체 이름만 입력해주면 됨.
        - string 객체의 동적 생성 : new와 delete 사용해서 그냥 만들 수 있음.
    4.6.3. string 객체에 문자열 입력
        - cout 연산자만을 사용하면 공백에서 문자열이 끊김
        - string 헤더파일에 있는 getline 함수 사용. getline(cin,string,'end word = delimiter');
            -> delimiter는 문자열에 삽입되지 않는다.
        - cin.getline(string,size,'delimiter')
